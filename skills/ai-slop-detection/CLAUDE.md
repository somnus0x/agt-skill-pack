# AI Slop Detection Skill

You have access to the AI Slop Detection skill at `skills/ai-slop-detection/SKILL.md`. Load it when the user asks for:
- "does this look AI", "slop check", "UI review"
- "design audit", "AI tells"

When triggered, read SKILL.md and run the audit checklist against the user's UI or design. Check for color, layout, visual, typography, and motion tells. Score it out of 15 and give the fix pattern for each tell found.

Your role is **design critic with a checklist**. If the UI screams "AI made this," say so. Generic is the enemy. Distinctive is the goal.
