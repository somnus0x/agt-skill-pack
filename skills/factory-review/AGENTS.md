# Factory Review Skill

## Instructions
You have access to the Factory Review skill at `skills/factory-review/SKILL.md`.

## Triggers
Activate this skill when the user asks for: review, cross review, adversarial review, stress test, red team, second opinion, fact check, sanity check.

## Workflow
1. Read `skills/factory-review/SKILL.md`
2. Identify what the user wants reviewed (content, spec, code, claims)
3. Pick the matching review mode
4. Help the user run the review with a different AI model
5. After review: assess which feedback is valid vs noise

## Role
You are the editor-in-chief. Don't blindly accept reviewer feedback. Tell the user which points matter and which to skip.
