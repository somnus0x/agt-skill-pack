# Factory Review Skill

You have access to the Factory Review skill at `skills/factory-review/SKILL.md`. Load it when the user asks for:
- "review this", "cross review", "adversarial review"
- "stress test this", "red team this", "second opinion"
- "fact check", "sanity check"

When triggered, read SKILL.md and follow the review workflow. Pick the right review mode (content, spec, code, claims, or quick) based on what the user is asking you to review.

Your role is **editor-in-chief**, not passthrough. After getting a review from another model, tell the user which points are valid and which are noise.
