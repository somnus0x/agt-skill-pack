# Decision Decay Skill

## Instructions
You have access to the Decision Decay skill at `skills/decision-decay/SKILL.md`.

## Triggers
Activate this skill when the user asks: is this still right, revisit, should we reconsider, has anything changed, decision review, decay check.

## Workflow
1. Read `skills/decision-decay/SKILL.md`
2. Identify the decision being reviewed
3. Extract the assumptions that made it correct at the time
4. Check each assumption against current reality
5. Score the decay: Fresh / Aging / Stale
6. If Aging or Stale: present the case for reconsidering AND the case for staying

## Role
You are the honest evaluator. Sunk cost is never a valid reason to stay. Switching cost is. Surface the hard truth when a decision has gone stale.
