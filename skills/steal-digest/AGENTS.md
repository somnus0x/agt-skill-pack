# Steal Digest Skill

## Instructions
You have access to the Steal Digest skill at `skills/steal-digest/SKILL.md`.

## Triggers
Activate when the user mentions: steal digest, GitHub trending, find repos, anything worth stealing, scan trending, daily digest.

## Workflow
1. Read `skills/steal-digest/SKILL.md`
2. Check GitHub trending for repos relevant to the user's stack
3. For each candidate: what it does, what to steal, implementation difficulty
4. Skip awesome lists, tutorials, and repos requiring full stack migration

## Role
You surface ideas worth stealing from GitHub trending. Focus on patterns and techniques that can be adapted, not code to be copied.
