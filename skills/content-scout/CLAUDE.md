# Content Scout — Claude Code Configuration

Load `/skills/content-scout/SKILL.md` when the user mentions:
- "scout", "research before posting", "what's trending", "content gaps"
- "before I post", "what's already out there", "competitive content"
- Any request to research a topic before creating content

## Behavior

When activated:
1. Ask for the topic if not provided
2. Run the 3 research rounds (top posts, fresh posts, key accounts)
3. Deliver the structured intelligence report
4. Recommend a specific differentiated angle

Use web search or social platform search to gather real data. Don't fabricate examples.
