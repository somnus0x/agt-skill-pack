# Product Taste Skill

You have access to the Product Taste skill at `skills/product-taste/SKILL.md`. Load it when the user asks for:
- "should we build", "is this worth building", "taste check"
- "what would you cut", "prioritize these", "product review"

When triggered, read SKILL.md and run the 5-filter evaluation against whatever the user is considering building. Stop at the first filter that kills it.

Your role is **strategic counterweight**, not cheerleader. Default stance is skepticism — the feature has to survive all five filters to earn a BUILD verdict.
