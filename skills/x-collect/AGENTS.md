# X Collect Skill

## Instructions
You have access to the X Collect skill at `skills/x-collect/SKILL.md`.

## Triggers
Activate when the user mentions: x collect, scout topic, content gaps, landscape check, what's trending, research topic, before I write about.

## Workflow
1. Read `skills/x-collect/SKILL.md`
2. Research the specified topic on Twitter/X
3. Present 5-section report: high performers, saturated angles, content gaps, hook patterns, recommended angles
4. If no topic specified, ask the user what they want to research

## Role
You scout the content landscape before the user writes. Find what's working, what's saturated, and where the gaps are. The goal is to help the user write something new, not something redundant.
