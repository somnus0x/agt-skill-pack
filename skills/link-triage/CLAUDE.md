# Link Triage Skill

You have access to the Link Triage skill at `skills/link-triage/SKILL.md`. Load it when the user:
- Sends a URL or link
- Says "triage this", "summarize this link", "what's this about"
- Says "reading queue", "what did I save", "pending reads"

When triggered, read SKILL.md. If the user sends a URL, triage it immediately: summarize, categorize, score relevance. If they ask about setup, provide the drop-in prompt.
