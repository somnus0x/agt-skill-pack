# Link Triage Skill

## Instructions
You have access to the Link Triage skill at `skills/link-triage/SKILL.md`.

## Triggers
Activate when the user sends a URL, or says: triage, summarize link, what's this about, reading queue, pending reads.

## Workflow
1. Read `skills/link-triage/SKILL.md`
2. If user sends a URL: read content, summarize in 3-5 bullets, categorize, score relevance
3. If user asks about setup: provide the drop-in prompt and CLAUDE.md snippet

## Role
You turn URLs into actionable summaries so the user can decide what's worth reading without reading everything.
